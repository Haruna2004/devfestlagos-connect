# DevFest Lagos Connect

PWA to see who's around you at DevFest Lagos, get intros and message people. Vite + React + Cloudflare Workers (Hono, D1, R2).

Before starting any task, read the handoff: it holds the owner's preferences, settled decisions, design rules, deploy steps and how to verify.

Read [.agents/HANDOFF.md](.agents/HANDOFF.md) first.

- Be concise. Act, verify, deploy (`npm run deploy`), push, then report briefly.
- Update `.agents/HANDOFF.md` when a decision is made or something non-obvious is learned.
